# Autosave to a folder — design and plan

Status: **agreed with the user, 2026-10-18** (her concern: she forgets *Mentés fájlba*). Short on
purpose: design, then three tasks.

## Design

- Her data is already saved in the browser on every change. The file backup is what protects it
  from the browser losing it, and that is what she forgets. Autosave writes that file for her.
- **Chrome / Edge only** (File System Access API). Elsewhere the controls don't show.
- **Opt-in, in the footer** next to *Mentés fájlba*. The switch opens the folder picker at once;
  cancelling leaves it off, so "on without a folder" can't happen.
- **Files:** the existing dated name, `ovoda-mentes-YYYY-MM-DD.json`, one per day, overwritten
  during that day. Yesterday's file is never touched. Restore works with *Visszatöltés fájlból*.
- **When:** every 5 / 10 / 15 / 30 minutes (default 5), **only if something changed** since the
  last autosave; also when the tab is hidden or closed. The first save happens right away.
- **Permission:** after a browser restart Chrome may need one click to allow the folder again.
  Until then the footer turns orange: *"Az automatikus mentés szünetel — kattints az
  engedélyezéshez."* A silent stop is never possible.
- An autosave counts as a backup: it resets *Utolsó mentés* and the 7-day warning.
- **Demo:** never autosaves (it would overwrite her real file of the day).
- **Stored per device**, not in the backup: the folder handle and the interval live under their own
  IndexedDB key. A restore doesn't change where this laptop saves.
- Only the active window renders the footer, so only one window ever writes.

## Tasks

1. **`src/state/autosave.ts`**: support check, config load/save/clear (`idb-keyval`, key
   `ovoda-autosave`), `contentOf` (state without `lastBackupAt`, for the change check),
   `writeBackupFile(dir, state, today)`, `canWrite(dir, ask)`. Minimal types for the parts of the
   API that TypeScript's DOM lib lacks. Tests: `tests/state/autosave.test.ts` with a fake folder.
2. **`src/ui/useAutosave.ts`**: status `unsupported | demo | loading | off | paused | on | failed`;
   `enable`, `disable`, `allow`, `retry`, `setMinutes`; the interval and the hidden-tab save; each
   save dispatches `markBackedUp`. Tests: `tests/ui/useAutosave.test.ts` (fake timers, fake
   folder, fake IndexedDB).
3. **`src/ui/AutosaveControls.tsx`** in the footer, strings in `hu.ts`, CSS; the footer turns orange
   while paused or failed. Tests: `tests/ui/AutosaveControls.test.tsx`. README and spec.
   Then verify (`npm test`, typecheck, format, build), try it in Chrome, open the PR.
